# 현재 홈페이지 기준 관리자 재구축 계획과 구현 상태

기준일: 2026-09-01

상세 연결표: `docs/admin-screen-linkage-report-2026-08-31.md`

## 목표

현재 고객 홈페이지의 문구와 디자인을 바꾸지 않고, 운영자가 고객 화면에서 시작해 실제 관리 위치를 찾고 등록·수정·삭제·노출·순서·게시를 이해할 수 있게 한다.

## 고정 원칙

1. 고객 홈페이지에 실제로 없는 기능은 관리자에서 제거한다.
2. 고객 화면에서 읽는 값만 관리자에 입력칸으로 둔다.
3. 같은 설정은 한 관리자 화면에서만 바꾼다.
4. 페이지 문구·이미지는 `임시저장 → 게시`, 상품·목록 데이터는 `저장 즉시 반영`을 사용한다.
5. 주문·회원처럼 삭제하면 안 되는 기록은 상태로 처리한다.
6. 인증·결제·재고·권한 같은 프로그램 안전 규칙은 관리자 콘텐츠 편집 대상에서 제외한다.
7. 보험은 별도 메뉴로 유지한다.
8. Production DB에는 테스트 데이터나 미검증 마이그레이션을 적용하지 않는다.

## 구현 완료

- `/admin/pages` 전체 화면 관리: 실제 고객 화면·주소·수정 영역·관리 버튼·가능 작업 표시
- `/admin/guide` 첫 직원용 사용 안내: 업무별 바로가기, 용어, 교육 완료 기준
- 공통 영역: 로고, 메뉴, 회사·고객센터, SNS, 서비스 노출 관리
- 홈: 배너·바로가기·이미지·버튼·카드·순서·노출·게시
- 상품: 기본 정보·가격·재고·옵션·이미지·본문 블록·배송·판매자
- 상품 태그: 배변·생활·피부 같은 카드 태그의 등록·수정·삭제·노출·순서
- 상품 진열: 베스트·추천·스토어 노출의 단일 관리 화면
- 브랜드: 카드·상세·Audit·배송·교환·대표상품·연관 고민
- 고민·케어 가이드: 카드·증상·빠른 안내·생활 팁·추천 상품·FAQ
- 맞춤 진단: 질문·답·일반화된 결과 조건·추천 연결·결과 공통 문구·질문·선택지·결과 순서
- 후기·공지·케어키트: 현재 고객 화면 데이터 CRUD
- Audit·B2B·전문가·케어키트 소개·목록 문구·법정 문서 CMS
- 상품 문의 답변·삭제, 제휴 문의 상태·메모·삭제
- 배송비 소유 화면을 브랜드로, 무통장 자동취소를 별도 운영 설정으로 분리
- 연결 없는 진단 참여 내역·제휴처 명부·수동 Q&A 삭제
- 고객 화면에서 읽지 않는 상품·브랜드·고민 입력칸 제거
- 현재 숨김 서비스는 실제 화면 목록에서 제외하고, 공통 영역에서 기능을 켜면 목록과 고객 메뉴에 함께 나타나도록 연결
- DB 적용 전 CMS·상품 태그 쓰기 버튼을 차단하고 기존 고객 화면 유지 상태와 다음 작업을 화면에 설명

## 실제 화면 확인

- 고객 홈페이지 35개 화면 캡처: `artifacts/public-screen-audit-20260831T011153Z/`
- 관리자 23개 화면 + 등록 화면 10개 최신 캡처: `artifacts/admin-screen-audit-20260831T091232Z/`
- 관리자 경로·등록 화면 누락·가로 깨짐 0건
- 고객 문서 오류·404·런타임 오류 문구·가로 깨짐 0건
- 발견한 숨김 전문가 화면 표시, CMS DB 전 빈 오류 화면, 태그 DB 전 활성 쓰기 버튼을 수정 후 재촬영
- 맞춤 진단 선택지의 위·아래 이동을 실제 브라우저에서 실행해 고객 표시 순서 변경을 확인
- 실제 상품 카드에 나오지 않던 `한 줄 설명` 입력은 제거하고, 상품 상세의 첫 설명 입력에 정확한 고객 화면 위치와 바로가기를 표시
- 실제 지급·사용 기능이 없는 적립금 설정과 고객 안내를 관리자·상품 계약·공개 화면에서 제거
- 상품 등록 화면에서 새 상품 태그 이름을 바로 등록하고 현재 상품에 자동 선택. 전체 수정·삭제·순서 변경은 `/admin/products/tags`로 연결하고, 상품 연결은 마지막 상품 저장으로 확정된다고 명시
- 상품 진열에서 홈 추천·스토어 추천·스토어 전체 순서를 화면별로 분리하고 상품마다 실제 노출 화면·순번·브랜드 대표상품 포함 여부·상세 주소를 표시. 기존 상품은 관리자가 처음 순서를 바꾸기 전까지 현재 홈페이지 정렬 유지
- 상품 카테고리 관리를 `/shop` 필터와 1:1로 맞춰 반려동물·상품 카테고리·가격 구간·평점 조건의 등록·수정·삭제·순서 변경을 제공. 브랜드·고민 필터는 중복 관리하지 않고 브랜드 관리·상품 태그 관리로 연결
- 이용약관·개인정보처리방침의 전달 원문과 누락 조항을 반영하고 시행일을 2026년 9월 1일로 통일. 두 문서 모두 관리자에서 조항 등록·수정·삭제·순서·게시 가능
- 오미프로·페네핏 로고는 글자를 유지한 투명 배경 자산으로 교체하고, 공통 사이트 로고는 모든 화면이 같은 `site-shell` 설정을 읽도록 통일
- 홈의 Audit 통과 배지와 `우리 아이를 위한 3가지 솔루션` 영역을 삭제하고, 사용되지 않는 솔루션 관리자 탭·저장 필드·전용 이미지도 함께 제거. 브라우저 확대·축소에서도 히어로가 전체 폭을 유지하도록 보정

## 최신 main 통합 후 코드 검증

- TypeScript 통과
- 상품·관리자 회귀검사 683개 통과
- 추적·보안 회귀검사 107개 통과
- lint 오류 0개, 기존 경고 14개
- production build는 소스 컴파일과 TypeScript까지 통과. 정적 페이지 생성은 로컬에서 Production Supabase DNS를 조회하지 못해 중단됐으며 staging 환경에서 재실행 필요
- 결제·배송 staging 검사는 `.env.test.local` 부재를 안전장치가 감지해 시작 전에 차단. Production DB 쓰기 없음
