| 주문 목록 | `/mypage?tab=orders` | `/api/orders/mine`, `/api/orders/mine/shipments` | ✅ 비로그인 차단·렌더 계약 확인 / ⚠️ 실제 회원 데이터 E2E 미실행 |

| 상품 문의 | 상품 상세·마이페이지 | `/api/products/[id]/inquiries`, `/api/inquiries/mine` | ✅ CRUD 계약 확인 / ⚠️ 실제 회원 E2E 미실행 |
| 1:1 문의 | `/mypage?tab=inquiries` | `/api/inquiries`, `/api/inquiries/[id]` | ✅ CRUD 계약 확인 / ⚠️ 실제 회원 E2E 미실행 |

## 3. 스토어 테스트 수정 요청

- [ ] 브랜드 필터 테스트가 DB 원본명 `RE:펫 (RE:PET)` 대신 화면 표시명 `RE:펫`을 사용하도록 수정
- [ ] 브랜드 상세 링크 기대값을 DB ID(`/brands/b3`)가 아니라 공개 슬러그(`/brands/nobledog` 등) 기준으로 수정
- [ ] 품절 혼합 상품이 반드시 존재한다고 가정하지 않도록 옵션 재고 테스트 픽스처 분리
- [ ] 전 상품 구매 가능 정책과 품절 차단 회귀 테스트를 서로 다른 픽스처로 검증
