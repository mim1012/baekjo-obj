## 코드 PR과 구분되는 로컬 복구

- 마이페이지 이동 오류: `.env.local`의 인증 주소가 3001로 되어 있어 3000으로 수정했다. 환경변수 파일은 커밋하지 않는다. 회원·관리자 실제 로그인 후 마이페이지 정상 표시를 확인했다.
- CMS 목록 오류: 로컬 DB에 CMS 테이블이 없어 기존 0162~0166 마이그레이션을 적용했다. 이 PR에 새 DB 마이그레이션은 없다. 로컬 DB 내용 및 비밀정보는 커밋하지 않는다. CMS 페이지 15개와 편집 상세 API 정상 조회를 확인했다.
- 기존 CMS에 이미지·내비게이션 게시값이 있으면 그 게시값이 우선한다. 이 PR은 이미 게시된 콘텐츠를 자동 덮어쓰지 않는다.
- 회사소개는 전용 CMS 본문 편집기를 새로 제공하지 않는다. 화면 관리표에서 공통 메뉴 편집으로 연결한다.
