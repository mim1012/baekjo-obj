### 테스트 환경 주의사항

- 개발 E2E 주소는 `http://localhost:3001`을 사용합니다.
- `http://127.0.0.1:3001`로 실행하면 Next.js 개발 서버의 교차 출처 HMR 차단 때문에 로딩 실패처럼 보이는 오탐이 발생합니다.
- `127.0.0.1`도 지원해야 한다면 Next.js `allowedDevOrigins` 설정을 추가합니다.

### 2. 취소·교환·반품·환불의 고객 신청 및 상태 추적이 없음

- [ ] 고객 신청 화면과 API 구현

- 완료 기준: 고객 신청 → 관리자 접수 → 처리 → 고객 상태 확인까지 전 과정 테스트 통과

- [ ] Toss 실결제 환경변수 및 웹훅 설정

- [ ] 개인정보 수집 목적, 보유 기간, 제3자 제공, 위탁사, 파기 절차 검토
- [ ] 보험 안내와 반려동물 건강 콘텐츠의 면책 문구 검토

## 권장 배포 순서

1. P0 코드 및 운영 정책 확정

3. 스테이징 DB 백업 후 마이그레이션 전체 적용

## 최종 Go / No-Go 기준

- [ ] P0 항목이 모두 완료되었거나 위험 승인 기록이 있음
- [ ] 자동화 테스트 실패 0건, 중요 스킵 0건
