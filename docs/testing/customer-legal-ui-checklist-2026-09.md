# 고객 화면 법적 안내 1차 테스트 체크리스트

대상 브랜치: `codex/p0-customer-legal-ui`

이 문서는 비개발자가 Preview 또는 staging 화면에서 직접 확인할 항목을 정리한다. 실제 주문을 생성하는 테스트는 반드시 staging 환경에서만 수행한다.

## 테스트 준비

- [ ] PC 화면(가로 1440px 전후)과 모바일 화면(가로 390px 전후)을 각각 확인한다.
- [ ] 일반 구매자 테스트 계정으로 로그인한다.
- [ ] 장바구니에는 판매 가능한 상품을 최소 1개 담는다.
- [ ] 주문완료 확인이 필요하면 실제 결제가 발생하지 않는 staging 무통장입금 주문을 사용한다.
- [ ] Production에서는 주문·결제·데이터 생성 테스트를 하지 않는다.

## 1. 홈페이지와 공통 푸터

- [ ] 홈페이지 추천상품 영역 아래에 `통신판매중개 안내`가 보인다.
- [ ] 페이지 맨 아래 푸터에도 같은 안내가 보인다.
- [ ] 안내에 `통신판매의 당사자가 아닙니다` 문구가 있다.
- [ ] 안내에 `백조 오브제가 부담하는 책임은 제외되지 않습니다` 문구가 있다.
- [ ] `이용약관에서 자세히 보기`를 누르면 `/terms`로 이동한다.
- [ ] 모바일에서 문구가 잘리거나 화면 밖으로 넘어가지 않는다.

## 2. 브랜드 목록

- [ ] `/brands` 제목과 소개에 `큐레이션 브랜드`가 표시된다.
- [ ] `검증 브랜드 수` 문구가 보이지 않는다.
- [ ] `안심하고 선택할 수 있는 안전성을 갖춘 브랜드` 문구가 보이지 않는다.
- [ ] `공개 자료와 브랜드 제출 자료`를 바탕으로 살펴본다는 안내가 보인다.
- [ ] SAFETY 항목에 표시·인증 자료와 사용상 주의사항을 확인한다는 문구가 보인다.
- [ ] PC와 모바일에서 브랜드 수와 설명이 겹치지 않는다.

## 3. BEST 상품과 상품 상세

- [ ] BEST 상품카드에 `BEST`와 `자체 큐레이션 · 기준 보기`가 함께 보인다.
- [ ] `기준 보기`를 누르면 `/audit`로 이동한다.
- [ ] 상품카드를 누르면 기존처럼 상품 상세로 이동한다.
- [ ] 상품 상세 구매 버튼 아래에 통신판매중개 안내가 보인다.
- [ ] 장바구니·바로구매·찜 버튼이 기존과 동일하게 작동한다.
- [ ] 모바일에서 BEST 안내가 잘리거나 다른 배지를 가리지 않는다.

## 4. 케어가이드

- [ ] `/concerns/tear` 등 각 케어가이드 상단에 의료 안내가 보인다.
- [ ] 관련 상품 추천 바로 앞에도 같은 의료 안내가 보인다.
- [ ] 한 페이지에 의료 안내가 총 2회 노출된다.
- [ ] `수의사의 진단·처방 또는 치료를 대신하지 않습니다`가 표시된다.
- [ ] `증상이 지속되거나 악화되는 경우 수의사와 상담` 안내가 표시된다.
- [ ] 추천상품과 보험 안내 등 기존 영역이 밀리거나 겹치지 않는다.

## 5. 장바구니·주문·마이페이지

- [ ] 상품이 담긴 `/cart` 상단에 통신판매중개 안내가 보인다.
- [ ] 수량 변경, 삭제, 주문하기 버튼이 기존처럼 작동한다.
- [ ] `/checkout` 제목 아래에 통신판매중개 안내가 보인다.
- [ ] 배송지 입력과 결제수단 선택을 방해하지 않는다.
- [ ] staging 무통장입금 주문 완료 후 `/order-complete`에 안내가 보인다.
- [ ] 마이페이지 주문내역 상단에도 같은 안내가 보인다.
- [ ] 주문 상세 열기와 주문취소 요청 버튼이 기존처럼 작동한다.

## 6. 배송·교환·환불 안내

- [ ] `/refund-policy` 시행일이 `2026년 9월 1일`이다.
- [ ] 서면 또는 전자문서를 받은 날부터 7일이라는 기준이 보인다.
- [ ] 상품 공급이 늦으면 상품 공급일부터 7일이라는 기준이 보인다.
- [ ] 계약내용과 다른 경우 상품 공급일부터 3개월 기준이 보인다.
- [ ] 그 사실을 안 날 또는 알 수 있었던 날부터 30일 기준이 보인다.
- [ ] 맞춤제작 상품은 사전 고지·별도 동의 등 법정 요건을 갖춘 경우에만 제한된다고 표시된다.

## 7. 개인정보처리방침

- [ ] `/privacy`의 개인정보 보호책임자 연락처가 `1544-9883`이다.
- [ ] `010-5683-1725` 번호가 화면 어디에도 보이지 않는다.
- [ ] 푸터·환불정책·개인정보처리방침의 대표번호가 모두 같다.

## 8. 이번 1차 작업에서 아직 완료되지 않는 항목

- [ ] 상품별 실제 판매업체 사업자정보 등록·노출
- [ ] 판매자별 장바구니 묶음
- [ ] 결제 단계 개인정보 제3자 제공 별도 동의와 기록
- [ ] 상품군별 법정 필수정보 입력
- [ ] 교환·반품 온라인 신청
- [ ] 주문제작 상품 별도 동의와 사진 보관·삭제 관리

위 항목은 문구 확인만으로 완료 처리하지 않고 후속 기능 개발과 별도 테스트를 진행한다.
